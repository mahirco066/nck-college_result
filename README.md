# نظام وتطبيق نتائج كلية شمال كردفان (North Kordofan College - Results App)

نظام أكاديمي متكامل لإدارة ونشر واستعلام نتائج طلاب كلية شمال كردفان، يتألف من:
1. **تطبيق موبايل متكامل للطلاب (Flutter):** يعمل على Android و iOS لاستعلام النتائج الفردية، وتفاصيل المقررات، والمعدل الفصلي والتراكمي، ومعاينة وطباعة وتنزيل إشعار النتيجة بصيغة PDF.
2. **لوحة تحكم إدارية سحابية (Admin Panel):** لإدارة الامتحانات والكنترول لرفع كشوفات النتائج PDF، استخراج بيانات الطلاب آلياً، إدارة السجلات، ومتابعة نسب النجاح.
3. **خادم REST API ومحرك توليد PDF:** يدعم المعالجة السريعة، إرجاع بيانات الطلاب بدقة، وتوليد إشعارات الدرجات الرسمية الموثقة.
4. **محاكي هاتف تفاعلي مباشر (Simulator):** لتجربة وفحص التطبيق فوراً من المتصفح دون الحاجة لأجهزة إضافية.

## كيفية تشغيل وبناء تطبيق الفلاتر (Flutter Mobile App)

1. الانتقال إلى مجلد تطبيق الفلاتر:
   ```bash
   cd d:\NKC_RESULT_APP\student_mobile_app
   ```
2. تثبيت الحزم:
   ```bash
   flutter pub get
   ```
3. تشغيل التطبيق على الهاتف أو المحاكي:
   ```bash
   flutter run
   ```
4. بناء حزمة أندرويد نهائية (APK):
   ```bash
   flutter build apk --release
   ```
   *سيكون الملف الناتج جاهزاً للتوزيع والتثبيت المباشر في مسار: `build/app/outputs/flutter-apk/app-release.apk`.*

## توثيق الـ REST API

| المسار (Endpoint) | الطريقة | الوظيفة | المعاملات (Parameters) |
| :--- | :---: | :--- | :--- |
| `/api/departments` | `GET` | جلب قائمة الكليات والتخصصات | لا يوجد |
| `/api/semesters` | `GET` | جلب قائمة الفصول الدراسية | لا يوجد |
| `/api/results/search` | `POST` | الاستعلام عن نتيجة طالب | `{ "student_id": "2023001", "department_id": "CS", "semester_id": 4 }` |
| `/api/results/:id/pdf` | `GET` | توليد ومعاينة إشعار النتيجة PDF | مع `?download=1` للتنزيل المباشر |
| `/api/admin/stats` | `GET` | إحصائيات لوحة التحكم | عدد الطلاب، نسب النجاح، الكشوفات |
| `/api/admin/results` | `GET` | قائمة النتائج مع فلاتر البحث | `?query=...&dept=...&semester=...` |
| `/api/admin/results` | `POST` | إضافة سجل نتيجة جديد | بيانات الطالب والمقررات والمعدل |
| `/api/admin/results/:id` | `PUT` | تعديل سجل نتيجة طالب | بيانات التعديل |
| `/api/admin/results/:id` | `DELETE` | حذف نتيجة طالب | ID السجل |
| `/api/admin/upload-pdf` | `POST` | رفع كشف نتيجة PDF واستخراج البيانات | ملف الـ PDF وبيانات الدفعة |
| `/api/admin/batches` | `GET` | سجل كشوفات الـ PDF المرفوعة | قائمة الملفات وروابط التنزيل |

## مميزات الأمان والخصوصية
1. **خصوصية درجات الطالب:** لا يرى الطالب كشوفات زملائه، بل يدخل رقمه الجامعي فيحصل على كشف درجاته الشخصي فقط.
2. **الاعتماد الإلكتروني:** يتم ختم وترويسة إشعار النتيجة PDF تلقائياً بشعار الكلية، رمز التحقق، والمعدل التراكمي المعتمد.
3. **دعم العمل دون اتصال:** يتضمن تطبيق الفلاتر آلية Fallback ذكية في حال انقطاع شبكة الإنترنت للأرقام المخزنة.
